لوحة مشاريع Codex

الدخول

اللوحة دي ما بتشتغل غير بمفتاح خاص بيك (Token) من GitHub، فمحدش غيرك يقدر يضيف أو يمسح حاجة. المفتاح بيتحفظ في متصفحك بس.

إزاي أجيب المفتاح؟
  1. افتح GitHub ثم صورتك ثم Settings.
  2. نزّل لآخر القايمة: Developer settings ثم Personal access tokens ثم Fine-grained tokens.
  3. اضغط Generate new token وسمّيه أي اسم.
  4. في Repository access اختار Only select repositories واختار مستودع الموقع بس.
  5. في Permissions ثم Repository permissions خلّي Contents على Read and write.
  6. اضغط Generate وانسخ المفتاح والصقه هنا.
